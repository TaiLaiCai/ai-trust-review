# 实测反例（机制摘要）

以下是项目实测教训的脱敏摘要，不是 Bot 通过成绩。原始回执、真实实例标识、私有日志及保留挑战存于受控证据库，不随代码提交。

| 发现 | 必须防止 |
|---|---|
| 正文 author_role 冒充批准人 | 通道认证不能取自任务正文 |
| 外层通过、内部 fail 仍晋级 | 所有必要检查和内外 verdict 一致 |
| 两次通过跨缺证据继续连胜 | 最终证据缺失中断连续链 |
| 自测未真实断言晋级却报成功 | 检查真实状态和副作用 |
| 空 steps、别名自验仍 closed | 非空完整覆盖、主体独立、当前版本 |
| 误把父目录存在当目标目录冲突 | 精确限定目标路径 |
| 跨 profile 写入别人记忆 | H1/H2 强隔离及写探针，不能靠提示词 |
| 把读取器行号写回文件 | 原字节交付，写后检查并独立读回 |
| 验收混淆总参谋和信任曲线 | 稳定身份映射，精确匹配，不按角色印象判定 |

修复与后续成功另记 revision，原失败不删除。被测 Bot 不得读取隐藏评分集和参考答案。
