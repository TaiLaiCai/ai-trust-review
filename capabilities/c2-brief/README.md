# C2 简报

一页简报，创作团队可直接开工（L2 / L3）。本目录是 Apo Labs 超级框架 §6 中 C2 岗位的原子能力落地，来源为框架文档的 §0 注入版与 §6 C2 专属契约，契约全文见 [prompt.md](prompt.md)。

## 目标

把已核验的热点、核验结论、窗口与存量匹配缺口，写成一页创作简报，让创作团队拿到就能开工（L2 改编 / L3 新作）。

## 验收

- 固定字段齐全：9 个固定字段一个不少，见 [prompt.md](prompt.md) 与 [fixtures/brief-input-demo.json](fixtures/brief-input-demo.json)。
- 所有数字引用事实 id：简报里的每个数字都能追溯到一条事实，不得出现无来源的数字。
- 含禁止相似边界：明确写出不得逼近的具体作品旋律、歌词与标志性元素，列出需避开的参照类型。

## 读→写

- 读：hotspot、verdict、窗口、match 缺口。
- 写：brief。

只读已核验的热点与匹配结果，不读私有账本，不写作品库，不写任何其他分区。

## 方式

只描述特征与主题，不给可直接复刻的具体旋律或歌词；一页为限。目标特征只写区间，不写具体旋律与歌词细节。

## 规则

- 只描述特征与主题，不给可直接复刻的具体旋律 / 歌词。
- 一页为限，超出篇幅要压缩，不得另起附页代替核心字段。
- 阶段与窗口截止给下界，样本不足时写明经验性参考与样本量。
- 禁止相似边界必须写清需避开的参照类型，不得含糊带过。
- 成品须人工审听后入库，由 A2 打标，本岗位不代审。

## 停止

出现以下任一情况立即停下，按路由处理，不得猜测继续写：

- 口径未定义，或目标、验收、口径模糊冲突。
- 事实 id 缺失，数字无法引用事实。
- 输入的 hotspot 未经核验，或 verdict 缺失。
- 被要求创作歌曲本身、发布、外发、花钱，或超出本目录 paths 的读写。
- 触发冻结契约中的 stop_when，见 [prompt.md](prompt.md)。

## 不做

- 不创作歌曲本身。
- 不发布。
- 不改阈值与口径，不改历史事实，不写私有账本字段。
- 不代行人工审听，不把低置信内容写成确定结论。
