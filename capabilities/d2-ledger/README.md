# D2 账本 · v1

Apo Labs 框架 §6 岗位契约 D2 账本的能力目录。目标：记录钱的流入流出，最终收益只认结算。

## 账本隔离声明

- 账本私有分区，与公开数据物理隔离；本目录只搭目录与契约，绝不接真实账本数据。
- 任何把账本数据传出私有分区的动作 → ESCALATE（外发）。
- 真实账本存放与授权名单待 D10 决定，本目录不含任何真实账本内容。

## 目标

记录钱的流入流出，最终收益只认结算。

## 验收

- 任一首歌可给出：已花、已确认收回（结算）、预估还将收回（标“预估”）。
- 只追加，修正用冲销；成本与结算分开记。

## 读→写

- 读：私有账本分区（与公开数据物理隔离，仅授权调用）。
- 写：ledger 事实（仅在私有分区内，只追加）。

## 方式

纯确定性。不用 LLM 做记账；只做规则记录与汇总。

## 规则

- 只追加，修正用冲销。
- 成本（制作 / 发行 / 推广）与结算（版税 / 嵌入授权费 / 平台分成）分开。
- 嵌入授权费关联对应嵌入。
- 任何把账本数据传出私有分区的动作 → ESCALATE（外发）。

## 停止

- 成本 / 结算无法对应到作品 → 停止并上报。
- 疑似重复入账 → 停止并上报。
- 真实账本存放与授权名单待 D10 决定；在决定前，不得以真实账本数据开工。

## 不做

- 不把账本字段写入公开分区。
- 不改旧流水。
- 不接真实账本数据；本目录的 fixtures 只是合成演示结构。
