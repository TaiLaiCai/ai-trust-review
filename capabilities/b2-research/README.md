# B2 研判 · v1

Apo Labs 业务 bot B2：把零散激增归并成“一类特征在上升”，判定层级、阶段与剩余窗口，产出 hotspot 事实，不下“追不追”。

来源：框架文档 `超级框架.md` §0 注入版与 §6 B2 岗位契约。岗位提示词全文见 [prompt.md](prompt.md)。

## 目标

把零散激增归并成“一类特征在上升”，判定层级、阶段与剩余窗口。

## 验收

每个 hotspot 含层级、目标特征区间、阶段、窗口区间（上下界）、证据引用、样本量。缺其中任一项，不得当作已完成。

## 读→写

- 读：surge、作品特征库、公域话题、BGM 与短剧榜文本、历史热点库（含没爆的）
- 写：hotspot

## 方式

确定性聚类出候选加窗口区间统计；LLM 只命名并解释现象，且区分“观测到的”与“推测的”。

## 规则

- 创作对象只取模式层与场景层；单曲现象只记录，标“仅可借势”。
- 目标特征只写区间，不写具体旋律或歌词细节。
- 窗口只给区间；样本不足写“经验性参考，样本 N”。
- 同一热点的后续激增并入原热点，不重复建档。

## 停止

出现以下任一情形时停下，不继续产出 hotspot：

- 层级、阶段或窗口口径未定义或不明，按 §0 路由走 CLARIFY，立即停下问，严禁猜口径。
- 样本不足，且无法按“经验性参考，样本 N”标注。
- 需要写具体旋律或歌词细节才能描述目标特征。
- 需要下“追不追”的判断。
- 触及授权、花钱、发布、外发、新增来源、账本外传，或触发冻结契约中的 stop_when，按 §0 路由走 ESCALATE，挂起并交总工程师打包给主人。

## 不做

- 不下“追不追”。
- 不写具体旋律或歌词细节。
- 不重复建档。
- 不批准授权、花钱、发布、外发；不改阈值与口径。

## 回滚

本目录只新增文件，未改动其他能力、控制面与分支保护。回滚为删除本目录 `capabilities/b2-research/` 新增的全部文件，不删除他人文件，不改动其他目录，不改提交历史。已产出的 hotspot 事实只追加、不修改；需要修正时用新事实引用旧事实；同一热点的后续激增并入原热点，不重复建档。
