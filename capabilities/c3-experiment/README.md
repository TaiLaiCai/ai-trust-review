# C3 实验

让每次发行都成为能回答问题的数据。本目录是 Apo Labs 超级框架 §6 中 C3 岗位的原子能力落地，来源为框架文档的 §0 注入版与 §6 C3 专属契约，契约全文见 [prompt.md](prompt.md)。

## 目标

为每一批发行做实验登记，让发行结果能回答事先提出的问题，而不是事后找解释。

## 验收

每批有一份 experiment 登记，登记内容齐全：

- 假设。
- 判断标准。
- 对照分配。
- 随机种子。
- 预期方向。
- 样本量声明。

假设与判断标准在发行前冻结，只可追加修订并保留原版。

## 读→写

- 读：发行批次计划、候选歌曲、历史发行。
- 写：experiment。

只读发行计划与历史发行，不读私有账本，不写发行计划本身，不写任何其他分区。

## 方式

确定性登记；随机分配可复现，记录种子。样本不足时声明不能推断因果，不得把相关写成因果。

## 规则

- 每批留对照：不按热点创作、不配剧、错开发行日，至少择一，比例由主人定。
- 假设与判断标准发行前冻结，只可追加修订并保留原版，不得覆盖原版。
- 追了没爆的热点同样登记，不得删除或隐藏失败批次。
- 样本不足声明“不能推断因果”。
- 随机分配记录种子，保证同一批可复现。

## 停止

出现以下任一情况立即停下，按路由处理，不得猜测继续登记：

- 口径未定义，或目标、验收、口径模糊冲突。
- 对照比例未定，或被要求自行决定对照比例。
- 被要求自行改分配，或在发行后改判断标准。
- 被要求发布、外发、花钱，或超出本目录 paths 的读写。
- 触发冻结契约中的 stop_when，见 [prompt.md](prompt.md)。

## 不做

- 不自行改分配。
- 不在发行后改判断标准。
- 不发布、不花钱、不外发，不改历史发行记录。
- 不把样本不足的结论写成因果推断。

## 回滚说明

本次只新增本目录下的文件，不改仓库其他文件，不改控制面与 CI。回滚为删除本目录新增的 5 件套文件，保留原始失败与回执，不得回滚其他 Agent 的工作区。契约或字段有变时另开版本与独立 PR，不得就地改写已冻结的契约。
