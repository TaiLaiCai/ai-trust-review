# A2 作品库 · v1

Apo Labs 框架 §6 的 A2 作品库岗位能力目录：把 3000+ 存量与每年新作变成可检索的作品库。

来源：Apo Labs 超级框架 v0.5（§0 注入版与 §6 A2 契约）。本目录只做目录化落地，不改框架口径，不做真实打标，不对外发布。

## 目标

把 3000+ 存量与每年新作变成可检索的作品库。

## 验收

- 任选一首，能列出各平台 ID 与全部特征。
- 标注覆盖率、待人审数、抽样一致率可报。
- 低置信标注标“待人审”，不入检索主索引。
- 新标注不覆盖旧标注（版本化）。

## 读→写

- 读：音频、元数据、自有后台 observation。
- 写：作品三层、平台 ID 映射、特征标注（版本化）。

## 方式

BPM、调式、时长用确定性音频分析；曲风、情绪、歌词主题、人声由 LLM 加受控词表，必须带置信度。

## 规则

- 特征包括曲风、BPM、调式、情绪、主题、人声、时长、历史表现分位（D7、D30，相对自家分布）。
- 词表受控，新增词条须人确认；低置信标“待人审”，不入检索主索引；抽样人审并记录一致率。
- 新标注不覆盖旧标注（版本化）。

## 停止

ID 冲突或疑似重复时，写冲突事实，交人判断。

## 不做

不据音频相似度判断版权（留给 C2 的禁止相似边界与人工审听）；不对外发布；不改历史标注。
