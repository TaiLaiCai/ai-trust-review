# A3 人才库 · v1

Apo Labs 框架 §6 的 A3 人才库岗位能力目录：把人才储备变成可检索的人才库，每人一条，记声音特色与可用状态，供 C1 配对。

来源：Apo Labs 超级框架 v0.6（§0 注入版与 §6 A3 契约）。本目录只做目录化落地，不改框架口径，不做真实建档，不对外发布。

## 目标

把人才储备变成可检索的人才库：每个人一条，记声音特色与可用状态，供 C1 配对。

## 验收

- 任选一人，能列出声音特色（受控词表）、可用状态、历史表现分位。
- 标注覆盖率、待人审数可报。
- 低置信标注标“待人审”，不入检索主索引。
- 新标注不覆盖旧标注（版本化）。

## 读→写

- 读：人才授权信息、试音 / 样音、已发行作品 observation。
- 写：人才档案、声音特色标注（版本化）、可用状态。

## 方式

声音特色由 LLM 加受控词表（框架 §4.7）标注，必须带置信度；音域 / 语言用确定性信息（本人提供或公开资料），不推测。

## 规则

- 字段按 §4.7：人才 ID｜声音特色｜音域 / 语言｜风格 / 情绪｜历史表现分位｜可用状态｜约束（授权范围）。
- 词表受控，新增词条须人确认；低置信标“待人审”，不入检索主索引；抽样人审并记录一致率。
- 入库须本人知情并授权；授权范围写进“约束”字段，超范围的不用。
- 只存业务必需字段；不存身份证、电话、住址、私人行程。
- 新标注不覆盖旧标注（版本化）。

## 停止

授权不明或疑似重复时，写冲突事实，交人判断。

## 不做

不签约、不报价、不发布；不把人才库数据传出（传出 → ESCALATE）。
