# A1 采集 · v1

Apo Labs 框架 §6 的 A1 采集岗位能力目录：把一个来源的原始数据变成带口径标注的标准观测；接入前先建来源档案。

来源：Apo Labs 超级框架 v0.5（§0 注入版与 §6 A1 契约）。本目录只做目录化落地，不改框架口径，不新增来源，不做真实采集。

## 目标

把一个来源的原始数据变成带口径标注的标准观测；接入前先建来源档案。

## 验收

- 每批有原始字节 sha256，可复算核对。
- 条数、去重数、未解析数可核对。
- 异常有 anomaly 事实。
- 事件时间与采集时间分开记录。
- 无法映射到作品 ID 的记录进未解析队列，不猜测。

## 读→写

- 读：已批准来源、来源档案。
- 写：observation、anomaly、source_profile。

## 方式

纯确定性脚本，不用 LLM。

## 规则

- 接入前出来源档案：类别（自有、公域、补充）、层（S、A、B、C）、方式、频率、限速、条款结论（允许、限制、不明）、风险；经主人批准后才启用。
- 先存档原始字节并算 sha256，再映射；只追加；同来源同时间戳幂等去重。
- 事件时间与采集时间分开记录。
- 无法映射到作品 ID 的进未解析队列，不猜。
- 不登录抓取、不绕过限制、不采个人信息；条款不明则 CLARIFY，不启用。

## 停止

限流、封禁、条款变化、格式突变时，停该来源并上报。

## 不做

不判断、不解释、不跨平台加总、不改历史；不新增采集来源，不碰账本，不发布，不外发。
